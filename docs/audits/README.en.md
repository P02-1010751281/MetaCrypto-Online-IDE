# Audit reports

This directory holds the project's audit and verification reports. Audit reports record what was checked, what the conclusion was, and what remains unchecked; they are kept apart from the standard entry pages. Audit conclusions are not certification, formal verification or a security proof.

Reports are grouped by source:

| Subdirectory | Content |
|---|---|
| [standards/](./standards/) | Standards documentation audits: source extraction, entry splitting, quality review and re-extraction verification |
| [project/](./project/) | Project audit: overall check of cryptographic primitives and the teaching surface |

## Standards documentation audits

| Report | What it answers |
|---|---|
| [SOURCE-LAYERS.md](./standards/SOURCE-LAYERS.md) | How the standard-source extraction layer and the structured reference layer divide responsibility |
| [SOURCE-QUALITY-AUDIT.md](./standards/SOURCE-QUALITY-AUDIT.md) | Quality review of source extraction: what is trustworthy and where the gaps are |
| [SOURCE-SPLIT-COVERAGE.md](./standards/SOURCE-SPLIT-COVERAGE.md) | Coverage of the split from source text to structured entries |
| [SOURCE-SPLIT-INVENTORY.md](./standards/SOURCE-SPLIT-INVENTORY.md) | Entry-by-entry inventory of source text to structured entries (generated by `npm run standards:inventory:write`) |
| [REEXTRACTION-REPORT.md](./standards/REEXTRACTION-REPORT.md) | Summary of the re-extraction and verification round |

> `SOURCE-SPLIT-INVENTORY.md` is generated and must not be hand-edited. After changing any `原文位置` (source location) or `项目状态` (project status) line on a standards page, rerun `npm run standards:inventory:write`.

## Reading boundaries

- Audit reports describe the state at a particular check date, not a live guarantee of current state; rerun the corresponding gate before quoting any specific number.
- Passing checks covers engineering regression and behaviour on selected inputs; it does not represent CAVP/ACVTS, CMVP/FIPS 140-3, constant-time, side-channel security or formal verification.
- The authoritative interpretation of standard clauses is the publisher's original text; see the [standards coverage matrix](../standards/COVERAGE.en.md).
